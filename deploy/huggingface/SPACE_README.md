# Actogram LabScout

Find the labs, people and studies behind a research topic, on a map, from PubMed, Europe PMC, ROR, NIH RePORTER, UKRI
Gateway to Research and ClinicalTrials.gov.

- **Web page:** type a topic, get a map, a table with the reason each lab came up, and Excel, CSV or JSON.
- **MCP server for AI assistants:** add `https://<this space>.hf.space/mcp` as a custom connector.

Code and documentation: https://github.com/actogram/scholar-mcp. Part of [Actogram Open Science](https://actogram.org).
